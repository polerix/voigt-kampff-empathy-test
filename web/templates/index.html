VOIGHT-KAMPFF EMPATHY TEST

A software emulation of the Voight-Kampff empathy test from Blade Runner and Do Androids Dream of Electric Sheep? — a terminal interview engine correlating fictional biometric readings against a question bank, built to run on a Raspberry Pi.

This is a personal, non-commercial project. No ownership of the Voight-Kampff name, Blade Runner, or associated intellectual property is claimed.
