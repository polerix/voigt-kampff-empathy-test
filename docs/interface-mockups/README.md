# Interface mockups

`splash.txt` is the boot/accreditation screen mockup — still accurate to
the real device and is what `web/templates/display.html` is based on
(exact copy is still TODO there).

Three earlier mockups (`diagnostic.txt`, `main.txt`, `test.txt`) were
removed: they showed on-screen question text, a `[back]`/`[next]` button
pair, and a data-entry form, none of which exist on the real device. The
subject-facing screens never show question text (the agent reads from
paper) and the only inputs are the three panel buttons plus the manual
camera focus button — see `docs/design/device.md`.
